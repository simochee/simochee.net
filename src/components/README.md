# コンポーネントの構成

依存の向きは上から下への一方向です。下の層は上の層を知りません。

| 層         | 置き場所     | 役割                                               | 記事データ       |
| ---------- | ------------ | -------------------------------------------------- | ---------------- |
| ページ     | `src/pages/` | URL と、そのページで出すものを決める               | 読む             |
| 枠         | `layout/`    | 全ページ共通の枠と、サイドバーの並び               | 読まない         |
| 記事       | `entry/`     | 記事の一覧・要約・前後の移動                       | props で受け取る |
| プラグイン | `plugins/`   | サイドバーに並ぶ 1 区画                            | 自分で読む       |
| 部品       | `ui/`        | ボタン・入力欄・アイコンなど、意味を持たない見た目 | 読まない         |

## 置き場所の決めかた

- **どのページにも出る**なら `layout/`。
- **記事 1 件、または記事の並び**を受け取って描くなら `entry/`。
- **サイドバーの 1 区画**なら `plugins/`。`layout/Plugin.astro` で題名の帯を付け、並び順は `layout/Sidebar.astro` だけが決めます。
- **2 か所以上で同じ見た目**が要るなら `ui/`。1 か所でしか使わない見た目は、使う場所にユーティリティクラスで書きます。

## 見た目の書きかた

- 色・書体・文字サイズは `src/styles/global.css` の `@theme` にあるものだけを使います。
- ボタンは `ui/Button.astro`、1 行の入力欄は `ui/TextField.astro`、複数行は `ui/TextArea.astro` を使い、枠線や背景を書き直しません。
- アイコンは `ui/Icon.astro` に名前を渡します。飾りなら `label` を省き、意味を持つなら `label` を渡します。

## 動きの付けかた

スクリプトが要る部品はカスタム要素にして `hidden` で出力し、要素の定義側で `hidden` を外します。スクリプトが動かないときに押せないボタンが残らず、view transition でページが差し替わっても動き続けます。

## サーバーから中身を読む部品

拍手、コメント、掲示板、アンケート、カウンターなど、書き込みや閲覧で変わるものは、ページには器だけを書き出し、カスタム要素が `/api/` から読んで中身を入れます。

- 繰り返す見た目（コメント 1 件など）は `<template>` に Astro で書き、`src/scripts/template.ts` の `stamp()` で複製して `data-slot` の要素に値を入れます。利用者の書いた文は `textContent` で入れ、HTML として解釈させません。
- サイドバーの部品は `src/scripts/shared-data.ts` の `onSidebar()` で 1 回の読み込みを分け合います。サイドバーはページ遷移で残るので、読むのは最初の 1 回と、書き込んだあとだけです。
- 一覧の拍手とコメントの数は `counts` で、ページごとに 1 回読みます。
- アクセスカウンターと閲覧者数は、ページを開くたびに `src/scripts/visit.ts` が送る知らせの返事を `onVisit()` で受け取ります。
- 書き込み欄には `ui/Turnstile.astro`（迷惑書き込みよけ）を置きます。
